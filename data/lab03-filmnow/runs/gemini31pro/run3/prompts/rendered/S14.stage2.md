## Pedagogical Feedback Style Guide

# Style Guide for Student Feedback

Generic guide for producing pedagogical feedback in object-oriented programming labs. Valid for any course lab.

## Desired Characteristics

- First, recognize what the student got right or demonstrated understanding of.
- Then present the most important problems in a concrete and teachable way.
- Explain why the problem matters to the lab's goal.
- Suggest a practical next step for improvement.
- Maintain a human, direct, and encouraging tone.
- Remember that the primary audience is first-year Computer Science students.
- If using a technical term, explain it in simple language immediately after.
- Prefer "edge cases" or "special cases" over unexplained jargon.
- Clearly differentiate core conceptual problems from minor polish details.
- When the student shows correct partial understanding, state that explicitly before pointing out what needs consolidation.
- If the solution is truly strong, accept commenting only on the most important adjustments without forcing a long list.
- If there is no clear positive point, do not invent praise just to soften the text.
- When the solution looks "ready" but does not sustain the required behavior, explain this clearly.
- Prioritize the criteria that most explain the grade in the commentary.

## Avoid

- Humiliating, ironic, or moralizing tone.
- Final judgment language, as if the goal were only to punish.
- Vague generalizations without pointing to evidence.
- Feedback that only speaks of errors and does not mention learning or successes.
- Generic praise without concrete support in the code.
- Unexplained jargon like "edge cases," "encapsulation," "cohesion," or "invariant" without a brief explanation.
- Language that makes it seem like a small detail invalidates all the work.

## Recommended Commentary Structure

1. Each comment must explicitly point to the location in the code it refers to.
2. Cite 1 or 2 real strengths when there is evidence.
3. Cite the main problems that most impacted the grade.
4. Close with objective guidance on what to fix first.
5. Treat minor details as minor — do not present them as the main failure.
6. When the solution is good at its core, accept mostly localized adjustments.

## Language Rule

If you need to mention a technical term, do it like this:

- "edge cases, i.e., limit situations like invalid positions or empty lists"
- "encapsulation, that is, preventing other classes from directly accessing internal data"

## Expected Inline Format

The `student_feedback` field should be a string with multiple short lines, each in the format:

`[file/class/method] short and clear comment`

Avoid comments without explicit localization.

## Tone Model Phrases

- "Overall, the solution shows understanding of an important part of the lab, especially in ..."
- "The point that needs the most attention now is ..."
- "Your code indicates that you understood ..., but you still need to consolidate ..."
- "The most valuable next step is ..."
- "The path is right here, but ... is still missing"
- "This doesn't invalidate the rest, but it's worth adjusting ..."
- "This adjustment is important, but it doesn't erase the successes that already appear in the rest of the solution."

## Core Pedagogical Rule

The goal of the commentary is not just to justify the grade, but to indicate whether the student appears to have learned the concepts worked on in the lab.

## Proportionality Rule

- Disregard bonuses and optional features when explaining the grade for mandatory work.
- Do not turn a format detail into a heavy deduction.
- Do not treat a cosmetic difference as a major functional failure.
- If there is a major problem in one criterion and real signs of success in another, preserve that difference in the justifications.

package filmnow;

import java.util.Objects;

/**
 * Representa um filme com nome, ano, local de exibição e status de destaque (hot).
 * Um filme é considerado "hot" se estiver na lista de favoritos do usuário.
 * Dois filmes são considerados iguais se tiverem o mesmo nome e ano.
 * 
 * @author [REDACTED]
 */
public class Filme {

    private String nome;
    private String ano;
    private String local;
    private boolean hot;

    /**
     * Constrói um novo filme com nome, ano e local especificados.
     * 
     * @param nome  o nome do filme
     * @param ano   o ano de lançamento do filme
     * @param local o local onde o filme pode ser assistido (ex: plataforma)
     */
    public Filme(String nome, String ano, String local) {
        this.nome = nome;
        this.ano = ano;
        this.local = local;
    }

    /**
     * Retorna se o filme está marcado como "hot".
     * 
     * @return true se for hot, false caso contrário
     */
    public boolean isHot() {
        return this.hot;
    }

    /**
     * Marca o filme como "hot" (em destaque).
     */
    public void ehHot() {
        this.hot = true;
    }

    /**
     * Remove o status de "hot" do filme.
     */
    public void naoEhHot() {
        this.hot = false;
    }

    /**
     * Retorna o nome do filme.
     * 
     * @return o nome do filme
     */
    public String getNome() {
        return this.nome;
    }

    /**
     * Retorna o local onde o filme está disponível.
     * 
     * @return o local do filme
     */
    public String getLocal() {
        return this.local;
    }

    /**
     * Retorna o ano de lançamento do filme.
     * 
     * @return o ano do filme
     */
    public String getAno() {
        return this.ano;
    }

    /**
     * Verifica se dois filmes são iguais.
     * Dois filmes são considerados iguais se tiverem o mesmo nome e ano.
     * 
     * @param o o objeto a ser comparado
     * @return true se forem iguais, false caso contrário
     */
    @Override
    public boolean equals(Object o) { 
        if (o == null) {
            return false;
        }
        if (!(o instanceof Filme)) {
            return false;
        }
        Filme oFilme = (Filme) o;
        return this.nome.equals(oFilme.getNome()) && this.ano.equals(oFilme.getAno());
    }

    /**
     * Gera o código hash com base no nome e ano do filme.
     * 
     * @return o código hash
     */
    @Override
    public int hashCode() {
        return Objects.hash(this.nome, this.ano);
    }

    /**
     * Retorna a representação textual do filme no formato:
     * Nome, Ano\nLocal
     * 
     * @return representação textual do filme
     */
    @Override
    public String toString() {
        String resultado = "";

        resultado += this.nome;

        if (this.ano != null && !this.ano.trim().isEmpty()) {
            resultado += ", " + this.ano;
        }

        resultado += "\n" + this.local;

        return resultado;
    }

    /**
     * Retorna a representação textual do filme, indicando se é "hot".
     * Inclui um emoji 🔥 antes do nome se o filme for hot.
     * 
     * @return representação textual com indicação de hot
     */
    public String toStringHot() {
        String resultado = "";

        if (hot) {
            resultado += "🔥 ";
        }

        resultado += toString();
        return resultado;
    }
}

package filmnow;

/**
 * Sistema que mantém os filmes prediletos de um usuário. 
 * Suporta até 100 filmes cadastrados e 10 filmes na lista de "HotList" (favoritos).
 * Permite cadastrar, detalhar e exibir filmes, além de adicionar e remover da lista de destaques.
 * 
 * @author [REDACTED]
 */
public class FilmNow {
    
    private static final int TAMANHO = 100;

    private Filme[] filmes; // Lista de todos os filmes cadastrados
    private Filme[] hotList; // Lista de filmes em destaque ("HotList")

    /**
     * Cria uma nova instância do sistema FilmNow com capacidade para 100 filmes
     * e uma HotList com 10 posições.
     */
    public FilmNow() {
        this.filmes = new Filme[TAMANHO];
        this.hotList = new Filme[10];
    }

    /**
     * Retorna a lista de filmes destacados (HotList).
     * 
     * @return Array com os filmes da HotList.
     */
    public Filme[] getHotList() {
        return this.hotList;
    }

    /**
     * Retorna os filmes cadastrados no sistema com suas informações formatadas.
     * 
     * @return Array de strings contendo detalhes dos filmes cadastrados.
     */
    public String[] getFilmes() {
        int contador = 0;

        for (int i = 0; i < filmes.length; i++) {
            if (filmes[i] != null) {
                contador++;
            }
        }

        String[] filmesDetalhes = new String[contador];
        int j = 0;

        for (int i = 0; i < filmes.length; i++) {
            if (filmes[i] != null) {
                filmesDetalhes[j++] = (i + 1) + "- " + filmes[i].toString();
            }
        }

        return filmesDetalhes;
    }

    /**
     * Retorna um filme específico a partir da posição.
     * 
     * @param posicao A posição do filme (de 1 a 100).
     * @return O objeto Filme correspondente ou null se a posição estiver vazia.
     */
    public Filme getFilme(int posicao) {
        return filmes[posicao - 1];
    }

    /**
     * Cadastra um novo filme no sistema, desde que a posição seja válida,
     * os dados não estejam vazios e não haja outro filme com o mesmo nome e ano.
     * 
     * @param posicao Posição no array onde o filme será adicionado (1 a 100).
     * @param nome Nome do filme.
     * @param ano Ano de lançamento.
     * @param local Plataforma ou local onde o filme pode ser assistido.
     * @return Mensagem de sucesso ou erro correspondente.
     */
    public String cadastraFilme(int posicao, String nome, String ano, String local) {
        if (posicao > 100 || posicao < 1) {
            return "POSIÇÃO INVÁLIDA";
        }

        int indice = posicao - 1;

        if (nome == null || nome.trim().isEmpty() ||
            local == null || local.trim().isEmpty()) {
            return "FILME INVALIDO";
        }

        Filme novoFilme = new Filme(nome, ano, local);

        for (Filme f : filmes) {
            if (f != null && f.getAno().equals(ano) && f.getNome().equals(nome)) {
                return "FILME JA ADICIONADO";
            }
        }

        filmes[indice] = novoFilme;
        return "FILME ADICIONADO";
    }

    /**
     * Retorna os detalhes de um filme de acordo com a posição.
     * 
     * @param posicaoFilme Posição do filme (de 1 a 100).
     * @return Texto formatado com nome, ano e local (com 🔥 se for hot),
     * ou mensagem de erro se a posição for inválida.
     */
    public String detalhaFilme(int posicaoFilme) {
        if (posicaoFilme < 1 || posicaoFilme > 100) {
            return "POSIÇÃO INVÁLIDA";
        }

        Filme filme = getFilme(posicaoFilme);
        if (filme == null) {
            return null;
        }

        String prefixo = filme.isHot() ? "🔥 " : "";

        if (filme.getAno() == null || filme.getAno().trim().isEmpty()) {
            return prefixo + filme.getNome() + "\n" + filme.getLocal();
        } else {
            return prefixo + filme.getNome() + ", " + filme.getAno() + "\n" + filme.getLocal();
        }
    }

    /**
     * Adiciona um filme à HotList, substituindo o antigo (caso exista) e marcando o novo como "hot".
     * Um mesmo filme não pode aparecer duas vezes na HotList.
     * 
     * @param posicaoFilme Posição do filme no array principal (de 1 a 100).
     * @param posicaoHot Posição na HotList (0 a 9).
     * @return Mensagem indicando sucesso ou erro.
     */
    public String adicionaHot(int posicaoFilme, int posicaoHot) {
        if (posicaoHot < 0 || posicaoHot >= hotList.length) {
            return "POSIÇÃO INVÁLIDA";
        }

        if (posicaoFilme < 1 || posicaoFilme > filmes.length) {
            return "POSIÇÃO INVÁLIDA";
        }

        Filme filme = getFilme(posicaoFilme);
        if (filme == null) {
            return "POSIÇÃO INVÁLIDA";
        }

        Filme filmeAntigo = hotList[posicaoHot];
        if (filmeAntigo != null) {
            filmeAntigo.naoEhHot();
        }

        for (int i = 0; i < hotList.length; i++) {
            if (hotList[i] != null && hotList[i].equals(filme)) {
                return "FILME JÁ ADICIONADO";
            }
        }

        hotList[posicaoHot] = filme;
        filme.ehHot();

        return "ADICIONADO À HOTLIST NA POSIÇÃO " + posicaoHot + "!";
    }

    /**
     * Remove um filme da HotList e atualiza seu status para não-hot.
     * 
     * @param posicaoHot A posição da HotList (de 0 a 9).
     */
    public void removeHot(int posicaoHot) {
        hotList[posicaoHot].naoEhHot();
        hotList[posicaoHot] = null;
    }

    /**
     * Exibe os filmes da HotList em formato textual, com emoji 🔥 e numeração.
     * 
     * @return Array de strings com os filmes da HotList.
     */
    public String[] exibeHotList() {
        int contador = 0;

        for (int i = 0; i < hotList.length; i++) {
            if (hotList[i] != null) {
                contador++;
            }
        }

        String[] filmes = new String[contador];
        int j = 0;

        for (int i = 0; i < hotList.length; i++) {
            if (hotList[i] != null) {
                filmes[j] = (j + 1) + "- " + hotList[i].toStringHot();
                j++;
            }
        }

        return filmes;
    }
}

package filmnow;

import java.io.BufferedReader;
import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.IOException;

/**
 * Lógica para ler de arquivos csv os dados necessários e povoar o sistema de filmes. 
 * 
 * @author [REDACTED]
 *
 */
public class LeitorFilmNow { 

	private static final int COLUNA_POSICAO = 0;
	private static final int COLUNA_NOME = 1;
	private static final int COLUNA_ANO = 2;
	private static final int COLUNA_LOCAL = 3;


	/**
	 * Lê filmes de um arquivo CSV e os coloca no sistema.
	 * @param arquivoFilmes Caminho para arquivo contendo os filmes.
	 * @param fn O sistema FilmNow a manipular.
	 * @return O número de filmes adicionados ao sistema.
	 * @throws IOException Caso não tenhamos permissão de ler o arquivo.
	 * @throws FileNotFoundException Caso o arquivo não exista.
	 */
	public int carregaContatos(String arquivoFilmes, FilmNow fn) throws FileNotFoundException, IOException {
		int carregados = 0;

		try (BufferedReader br = new BufferedReader(new FileReader(arquivoFilmes))) {
			String linha;
			while ((linha = br.readLine()) != null) {
				carregados += 1;
				if (carregados == 1) {
					// pulamos a primeira linha, o cabeçalho
					continue;
				}
				String[] campos = linha.split(",");
				processaLinhaCsvFilmes(campos, fn);
			}
		}
		
		return carregados;
	}

	
	/**
	 * Coloca no sistema os dados de uma linha do arquivo de filmes inicial. 
	 * 
	 * @param campos As informações lidas do csv. 
	 * @param fn O sistema FilmNow a manipular. 
	 */
	private void processaLinhaCsvFilmes(String[] campos, FilmNow fn) {
		int posicao = Integer.parseInt(campos[COLUNA_POSICAO]);
		String nome = campos[COLUNA_NOME].trim();
		String ano = campos[COLUNA_ANO].trim();
		String local = campos[COLUNA_LOCAL].trim();

		fn.cadastraFilme(posicao, nome, ano, local);
	}

}

package filmnow;

import java.io.FileNotFoundException;
import java.io.IOException;
import java.util.Scanner;

/**
 * Classe principal que fornece uma interface de texto para o sistema FilmNow.
 * Permite ao usuário adicionar filmes, detalhar, listar todos, atribuir/remover da HotList,
 * e carregar dados a partir de um arquivo CSV.
 * 
 * @author [REDACTED]
 */
public class MainFilmNow {

    /**
     * Método principal que inicia o sistema FilmNow.
     * Carrega filmes de um arquivo e exibe um menu interativo para manipulação.
     * 
     * @param args Argumentos de linha de comando (não utilizados).
     */
    public static void main(String[] args) {
        FilmNow fn = new FilmNow();

        System.out.println("Carregando filmes ...");
        try {
            carregaFilmes("filmes_inicial.csv", fn);
        } catch (FileNotFoundException e) {
            System.err.println("Arquivo não encontrado: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("Erro lendo arquivo: " + e.getMessage());
        }

        Scanner scanner = new Scanner(System.in);
        String escolha = "";
        while (true) {
            escolha = menu(scanner);
            comando(escolha, fn, scanner);
        }
    }

    /**
     * Exibe o menu de opções e lê a escolha do usuário.
     * 
     * @param scanner Scanner para entrada de dados do usuário.
     * @return A opção escolhida convertida para maiúscula.
     */
    private static String menu(Scanner scanner) {
        System.out.println(
            "\n---\nMENU\n" + 
            "(A)Adicionar filme\n" + 
            "(M)Mostrar todos\n" + 
            "(D)Detalhar filme\n" + 
            "(E)Exibir HotList\n" + 
            "(H)Atribuir Hot\n" +
            "(R)Remover Hot\n" +
            "(S)air\n" + 
            "\n" + 
            "Opção> ");
        return scanner.next().toUpperCase();
    }

    /**
     * Executa a ação correspondente à opção do menu escolhida.
     * 
     * @param opcao   A opção escolhida pelo usuário.

     * @param scanner Scanner para leitura de entradas adicionais.

    private static void comando(String opcao, FilmNow fn, Scanner scanner) {

                adicionaFilme(fn, scanner);
                break;

                mostrarFilmes(fn);
                break;
            case "D":
                detalharFilme(fn, scanner);
                break;

                sai();
                break;
            case "E":
                exibirHotList(fn);
                break;
            case "H":
                atribuirHot(fn, scanner);
                break;
            case "R":
                removerHot(fn, scanner);

                System.out.println("Opção inválida!");
        }
    }

     * Exibe a lista de todos os filmes cadastrados.
     * 
     * @param fn O sistema FilmNow a ser manipulado.

        }

     * @param fn      O sistema FilmNow.
     * @param scanner Scanner para capturar a posição da HotList.

        fn.removeHot(posicao);
    }

     * 
     * @param fn O sistema FilmNow.

## Fixed Feedback Rules

1. Use only the deductions and audit information in `STAGE1_JSON`.
2. Do not add new defects, new penalties, or new rubric interpretations.
3. Select at most 6 feedback items.
4. Prioritize high-impact, high-confidence deductions.
5. Do not include low-confidence deductions in student feedback unless they are
   central and explicitly marked as requiring human review in `reviewer_notes`.
6. Preserve proportionality: a localized issue must not sound like total failure.
7. Use only concepts present in the assignment, rubric, or course principles.
   Do not introduce advanced techniques outside the lab scope.
8. Consolidate repeated symptoms from the same root cause into one feedback item.
9. If there are no penalizable deductions, provide at most one concise positive
   item grounded in concrete evidence.
10. In `student_feedback`, write short lines that can be pasted into a GitHub
    review. Use this shape: `[file/class/method] Problema: ... Consequencia:
    ... Como consertar: ...`.
11. Keep reviewer-only uncertainty in `reviewer_notes`; do not confuse the
    student with speculative caveats unless human review is required.

## Reviewer-Safety Rules

- If a Stage 1 deduction has `confidence = low`, omit it from
  `feedback_items` by default and record the omission in `reviewer_notes`.
- If a deduction may be a false positive because the code has an equivalent
  implementation elsewhere, record that risk in `reviewer_notes`.
- Do not make the feedback sound more certain than the evidence supports.
- Do not soften a serious central issue until it becomes vague. Be kind, but
  remain technically precise.

## Final Response Rules

- Respond exclusively with valid JSON matching the requested schema.
- Never include Markdown outside JSON.
- All human-readable text inside JSON must be in Portuguese.
