## Pedagogical Feedback Style Guide

# Style Guide for Student Feedback

Generic guide for producing pedagogical feedback in object-oriented programming labs. Valid for any course lab.

## Desired Characteristics

- First, recognize what the student got right or demonstrated understanding of.
- Then present the most important problems in a concrete and teachable way.
- Explain why the problem matters to the lab's goal.
- Suggest a practical next step for improvement.
- Maintain a human, direct, and encouraging tone.
- Remember that the primary audience is first-year Computer Science students.
- If using a technical term, explain it in simple language immediately after.
- Prefer "edge cases" or "special cases" over unexplained jargon.
- Clearly differentiate core conceptual problems from minor polish details.
- When the student shows correct partial understanding, state that explicitly before pointing out what needs consolidation.
- If the solution is truly strong, accept commenting only on the most important adjustments without forcing a long list.
- If there is no clear positive point, do not invent praise just to soften the text.
- When the solution looks "ready" but does not sustain the required behavior, explain this clearly.
- Prioritize the criteria that most explain the grade in the commentary.

## Avoid

- Humiliating, ironic, or moralizing tone.
- Final judgment language, as if the goal were only to punish.
- Vague generalizations without pointing to evidence.
- Feedback that only speaks of errors and does not mention learning or successes.
- Generic praise without concrete support in the code.
- Unexplained jargon like "edge cases," "encapsulation," "cohesion," or "invariant" without a brief explanation.
- Language that makes it seem like a small detail invalidates all the work.

## Recommended Commentary Structure

1. Each comment must explicitly point to the location in the code it refers to.
2. Cite 1 or 2 real strengths when there is evidence.
3. Cite the main problems that most impacted the grade.
4. Close with objective guidance on what to fix first.
5. Treat minor details as minor — do not present them as the main failure.
6. When the solution is good at its core, accept mostly localized adjustments.

## Language Rule

If you need to mention a technical term, do it like this:

- "edge cases, i.e., limit situations like invalid positions or empty lists"
- "encapsulation, that is, preventing other classes from directly accessing internal data"

## Expected Inline Format

The `student_feedback` field should be a string with multiple short lines, each in the format:

`[file/class/method] short and clear comment`

Avoid comments without explicit localization.

## Tone Model Phrases

- "Overall, the solution shows understanding of an important part of the lab, especially in ..."
- "The point that needs the most attention now is ..."
- "Your code indicates that you understood ..., but you still need to consolidate ..."
- "The most valuable next step is ..."
- "The path is right here, but ... is still missing"
- "This doesn't invalidate the rest, but it's worth adjusting ..."
- "This adjustment is important, but it doesn't erase the successes that already appear in the rest of the solution."

## Core Pedagogical Rule

The goal of the commentary is not just to justify the grade, but to indicate whether the student appears to have learned the concepts worked on in the lab.

## Proportionality Rule

- Disregard bonuses and optional features when explaining the grade for mandatory work.
- Do not turn a format detail into a heavy deduction.
- Do not treat a cosmetic difference as a major functional failure.
- If there is a major problem in one criterion and real signs of success in another, preserve that difference in the justifications.

package filmnow;

import java.util.Objects;

/**
 * Rpresenta um filme, que possui um nome, ano, local e se é considerado "hot".
 * Filmes são identificados unicamente pelo seu nome e o ano de lançamento.
 */
public class Filme {
	
	/**
	 * Nome do filme.
	 */
	private String nome;
	
	/**
	 * Ano de lançamento do filme. Pode ser null se não for especificado.
	 */
	private String ano;
	
	/**
	 * Local onde o filme é exibido ou onde se passa. 
	 */
	private String local;
	
	/**
	 * Indica se o filme é "hot".
	 */
	private boolean hot;

	/**
	 * Constói um filme a partir do nome e do local.
	 * O ano é opcional e será inicializado como null.
	 * O status "hot" é inicializado como false.
	 *
	 * @param nome O nome do filme.
	 * @param local O local de exibição ou onde o filme se passa.
	 */
	public Filme(String nome, String local) {
		this.nome = nome;
		this.local = local;
		this.hot = false;
	}
	
	/**
	 * Constrói um filme a partir do seu nome, ano de lançamento e local.
	 * O status "hot" é inicializado como false.
	 *
	 * @param nome O nome do filme.
	 * @param ano O ano de lançamento do filme.
	 * @param local O local de exibição ou onde o filme se passa.
	 */
	public Filme(String nome, String ano, String local) {
		this.nome = nome;
		this.ano = ano;
		this.local = local;
		this.hot = false;
	}
	

	public String getNome() {
		return this.nome;
	}

	public String getAno() {
		return this.ano;
	}
		
	public String getLocal() {
		return this.local;
	}
	
	public void setHot(boolean hot) {
		this.hot = hot;
	}
	
	public boolean getHot() {
		return this.hot;
	}
	
	@Override
	public int hashCode() {
		return Objects.hash(this.nome, this.ano);
	}

	@Override
	/**
	 * Compara este filme com outro objeto para verificar se são iguais.
	 * Dois filmes são considerados iguais se tiverem o mesmo nome e ano.
	 *
	 * @param o O objeto a ser comparado com este filme.
	 * @return true se o objeto for um filme com o mesmo nome e ano; {@code false} caso contrário.
	 */
	public boolean equals(Object o) {
		if (o == null) return false;
		if (!(o instanceof Filme)) return false;
		Filme oFilme = (Filme) o;
		if ((this.nome.equals(oFilme.getNome())) && (this.ano.equals(oFilme.getAno()))) return true;
		return false;
	}
	
	@Override
	/**
	 * Retorna uma representação em string do filme no formato "nome, ano".
	 * Se o ano for null, apenas o nome é retornado.
	 *
	 * @return Uma string representando o filme.
	 */
	public String toString() {
		if (this.ano == null) return this.nome;
		else return this.nome + ", " + this.ano;
	}
}

package filmnow;

/**
 * O sistema FilmNow gerencia uma lista de filmes e uma lista de filmes "hot".
 * O sistema suporta até 100 filmes e uma hotlist com até 10 filmes.
 * 
 * @author [REDACTED]
 */
public class FilmNow {

    /**
     * Tamanho máximo da lista de filmes.
     */
    private static final int TAMANHO = 100;
    
    /**
     * Tamanho máximo da hotlist.
     */
    private static final int TAMANHOHOTLIST = 10;
    
    /**
     * Array que armazena os filmes adicionados ao sistema.
     */
    private Filme[] filmes; 
    
    /**
     * Array que armazena a lista de filmes "hot".
     */
    private Filme[] hotList;
    
    /**
     * Construtor que cria uma instância do sistema FilmNow.
     * Inicializa as listas de filmes e hotlist com os tamanhos máximos.
     */
    public FilmNow() {
        this.filmes = new Filme[TAMANHO];
        this.hotList = new Filme[TAMANHOHOTLIST];
    }
    
    /**
     * Retorna uma cópia da lista de filmes mantida pelo sistema. 
     *
     * @return O array de filmes.
     */
    public Filme[] getFilmes() {
        return this.filmes.clone();
    }

    /**
     * Retorna uma representação em string do filme na posição.
     * 
     * @param posicao A posição do filme no sistema.
     * @return a representação do filme em string.
     */
    public String getFilme(int posicao) {
        return filmes[posicao].toString();
    }
    
    /**
     * Retorna uma cópia da hotlist.
     *
     * @return O array da hotlist.
     */
    public Filme[] getHotList() {
        return this.hotList.clone();
    }
    
    /**
     * Verifica se a posição é uma posição válida, considerando o tamanho do array filmes.
     *
     * @param posicao A posição a ser verificada.
     * @return true se a posição estiver dentro do intervalo válido, false caso contrário.
     */
    private boolean posicaoValida(int posicao) {
        return (posicao < TAMANHO && posicao >= 0);
    }
    
    /**
     * Adiciona um filme em uma posição específica. Se já houver um filme na posição, o filme anterior é substituído.
     * Além disso, remove da hotlist o filme anterior.
     * 
     * @param posicao A posição a ser inserida no array.
     * @param nome Nome do filme.
     * @param ano Ano de lançamento do filme.
     * @param local Local onde o filme pode ser assistido.
     * 
     * @return Mensagem de resultado da operação.
     */
    public String cadastraFilme(int posicao, String nome, String ano, String local) {
        posicao -= 1; // normaliza o índice passado pelo usuário.
        if (!posicaoValida(posicao)) return "POSIÇÃO INVÁLIDA!";
        if (nome.isBlank()) return "FILME INVÁLIDO!";
        if (jaExisteFilme(nome, ano)) return "FILME JÁ ADICIONADO";
        if (local.isBlank()) return "FILME INVÁLIDO!";
        if (ano.isBlank()) ano = null;
        removeHot(procuraPosicaoHot(posicao)); // ao sobrescrever um filme, o filme preexistente deve deixar de ser hot.
        this.filmes[posicao] = new Filme(nome, ano, local);
        return "FILME ADICIONADO!";
    }
    
    /**
     * Verifica se um filme com o nome e ano especificados já existe na lista de filmes.
     *
     * @param nome Nome do filme.
     * @param ano Ano de lançamento do filme.
     * @return true se o filme já estiver na lista, {@code false} caso contrário.
     */
    private boolean jaExisteFilme(String nome, String ano) {
        Filme filmeEscolhido = new Filme(nome, ano, "");
        for (int i = 0; i < this.filmes.length; i++) {
            if (this.filmes[i] != null && this.filmes[i].equals(filmeEscolhido)) {
                return true; 
            }
        }
        return false;
    }
    
    /**
     * Retorna os detalhes formatados de um filme na posição especificada.
     * Se o filme estiver na hotlist, o emoji"🔥" será adicionado na representação.
     * 
     * @param filmeIndex A posição do filme no sistema.
     * @return Detalhes formatados do filme ou uma mensagem de erro se a posição for inválida.
     */
    public String detalhaFilme(int filmeIndex) {
        filmeIndex -= 1;
        String filmeFormatado;
        if (posicaoValida(filmeIndex) && this.filmes[filmeIndex] != null) {
            if (ehHot(filmeIndex)) filmeFormatado = "🔥 " + formataFilme(filmeIndex);
            else filmeFormatado = formataFilme(filmeIndex);
            return filmeFormatado;
        }
        return "POSIÇÃO INVÁLIDA!";
    }
    
    /**
     * Formata os detalhes de um filme, incluindo o nome e o local com a primeira letra maiúscula.
     * 
     * @param filmeIndex A posição do filme.
     * @return Detalhes formatados do filme.
     */
    private String formataFilme(int filmeIndex) {
        String filmeFormatado;
        Filme filme = this.filmes[filmeIndex];
        String localFormatado = filme.getLocal().substring(0, 1).toUpperCase() + filme.getLocal().substring(1);
        filmeFormatado = filme.toString() + "\n" + localFormatado;
        return filmeFormatado;
    }
    
    /**
     * Verifica se a posição especificada é válida para a hotlist.
     *
     * @param posicao A posição a ser verificada.
     * @return true se a posição estiver dentro do intervalo válido para a hotlist, false caso contrário.
     */
    private static boolean posicaoValidaHot(int posicao) {
        return (posicao < TAMANHOHOTLIST && posicao >= 0);
    }
    
    /**
     * Adiciona um filme à hotlist na posição especificada. Se o filme já estiver na hotlist, o filme não
     * é adicionado. Verifica também se vai ser inserido em uma posição válida ou se é um filme válido.
     * 
     * @param posicaoFilme A posição do filme na lista de filmes (1-based index).
     * @param posicaoHot A posição na hotlist (1-based index).
     * @return Mensagem de resultado da operação.
     */
    public String cadastraHot(int posicaoFilme, int posicaoHot) {
        posicaoFilme -= 1; // normaliza o índice do filme.
        posicaoHot -= 1; // normaliza o índice da hotlist.
        if (!posicaoValida(posicaoFilme) || this.filmes[posicaoFilme] == null) return "POSIÇÃO DO FILME INVÁLIDA!";
        if (!posicaoValidaHot(posicaoHot)) return "POSIÇÃO INVÁLIDA PARA A HOTLIST!";
        if (ehHot(posicaoFilme)) return "O FILME JÁ ESTÁ NA HOTLIST!";
        this.hotList[posicaoHot] = this.filmes[posicaoFilme];
        this.filmes[posicaoFilme].setHot(true);
        return "ADICIONADO À HOTLIST NA POSIÇÃO " + (posicaoHot + 1) + "!";
    }

    /**
     * Verifica se um filme na posição especificada está na hotlist.
     *
     * @param posicaoFilme A posição do filme na lista de filmes.
     * @return true se o filme estiver na hotlist, false caso contrário.
     */
    private boolean ehHot(int posicaoFilme) {
        return filmes[posicaoFilme].getHot();
    }
    
    /**
     * Remove um filme da hotlist na posição especificada. O filme é removido e seu status "hot" é atualizado.
     * 
     * @param posicaoFilme A posição do filme na lista de filmes.
     * @return Mensagem de resultado da operação.
     */
    public String removeHot(int posicaoHot) {
        posicaoHot -= 1;
        if (!posicaoValidaHot(posicaoHot) || this.hotList[posicaoHot] == null) return "POSIÇÃO INVÁLIDA!";
        this.hotList[posicaoHot].setHot(false);
        this.hotList[posicaoHot] = null;
        return "";
    }
    
    /**
     * Procura um filme da HotList pela posição do filme na lista de filmes.
     * Se o filme existir na HotList, retorna a posição do filme a HotList.
     * Caso contrário, retorna -1.
     * 
     * @param posicao a posição do filme na lista.
     * @return a posição do filme na hotlist.
     */
    private int procuraPosicaoHot(int posicao) {
    	for (int i = 0; i < this.hotList.length; i++) {
    		if (this.filmes[posicao] != null && this.hotList[i] != null) {
    			if (this.filmes[posicao].equals(this.hotList[i])) return i + 1;
    		}
    	}
    	return -1;
    }
}

package filmnow;

import java.io.BufferedReader;
import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.IOException;

/**
 * Lógica para ler de arquivos csv os dados necessários e povoar o sistema de filmes. 
 * 
 * @author [REDACTED]
 *
 */
public class LeitorFilmNow {

	private static final int COLUNA_POSICAO = 0;
	private static final int COLUNA_NOME = 1;
	private static final int COLUNA_ANO = 2;
	private static final int COLUNA_LOCAL = 3;

	/**
	 * Lê filmes de um arquivo CSV e os coloca no sistema.
	 * @param arquivoFilmes Caminho para arquivo contendo os filmes.
	 * @param fn O sistema FilmNow a manipular.
	 * @return O número de filmes adicionados ao sistema.
	 * @throws IOException Caso não tenhamos permissão de ler o arquivo.
	 * @throws FileNotFoundException Caso o arquivo não exista.
	 */
	public int carregaContatos(String arquivoFilmes, FilmNow fn) throws FileNotFoundException, IOException {
		int carregados = 0;

		try (BufferedReader br = new BufferedReader(new FileReader(arquivoFilmes))) {
			String linha;
			while ((linha = br.readLine()) != null) {
				carregados += 1;
				if (carregados == 1) {
					// pulamos a primeira linha, o cabeçalho
					continue;
				}
				String[] campos = linha.split(",");
				processaLinhaCsvFilmes(campos, fn);
			}
		}
		
		return carregados;
	}

	/**
	 * Coloca no sistema os dados de uma linha do arquivo de filmes inicial. 
	 * 
	 * @param campos As informações lidas do csv. 
	 * @param fn O sistema FilmNow a manipular. 
	 */
	private void processaLinhaCsvFilmes(String[] campos, FilmNow fn) {
		int posicaoIndex = Integer.parseInt(campos[COLUNA_POSICAO]); 
		String nome = campos[COLUNA_NOME].trim();
		String ano = campos[COLUNA_ANO].trim();
		String local = campos[COLUNA_LOCAL].trim();

		fn.cadastraFilme(posicaoIndex, nome, ano, local);
	}
}

## Fixed Feedback Rules

1. Use only the deductions and audit information in `STAGE1_JSON`.
2. Do not add new defects, new penalties, or new rubric interpretations.
3. Select at most 6 feedback items.
4. Prioritize high-impact, high-confidence deductions.
5. Do not include low-confidence deductions in student feedback unless they are
   central and explicitly marked as requiring human review in `reviewer_notes`.
6. Preserve proportionality: a localized issue must not sound like total failure.
7. Use only concepts present in the assignment, rubric, or course principles.
   Do not introduce advanced techniques outside the lab scope.
8. Consolidate repeated symptoms from the same root cause into one feedback item.
9. If there are no penalizable deductions, provide at most one concise positive
   item grounded in concrete evidence.
10. In `student_feedback`, write short lines that can be pasted into a GitHub
    review. Use this shape: `[file/class/method] Problema: ... Consequencia:
    ... Como consertar: ...`.
11. Keep reviewer-only uncertainty in `reviewer_notes`; do not confuse the
    student with speculative caveats unless human review is required.

## Reviewer-Safety Rules

- If a Stage 1 deduction has `confidence = low`, omit it from
  `feedback_items` by default and record the omission in `reviewer_notes`.
- If a deduction may be a false positive because the code has an equivalent
  implementation elsewhere, record that risk in `reviewer_notes`.
- Do not make the feedback sound more certain than the evidence supports.
- Do not soften a serious central issue until it becomes vague. Be kind, but
  remain technically precise.

## Final Response Rules

- Respond exclusively with valid JSON matching the requested schema.
- Never include Markdown outside JSON.
- All human-readable text inside JSON must be in Portuguese.
